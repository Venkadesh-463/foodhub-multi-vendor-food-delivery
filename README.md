# FoodHub - Professional Food Delivery Platform

## Overview

FoodHub is a full-featured food delivery web application developed using PHP, MySQL, HTML, CSS, and JavaScript. The platform connects customers, restaurants, delivery partners, and administrators within a single ecosystem.

The project follows a modular architecture and includes separate dashboards, APIs, authentication systems, order management, payment handling, delivery tracking, and restaurant administration.
